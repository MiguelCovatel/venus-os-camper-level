Camper Level

Instalador para ESP32-C3 SuperMini + MPU-6500/9250

Antes de empezar

  1. Utiliza Chrome o Edge en un ordenador.
  2. Conecta el ESP32-C3 por USB.
  3. Cierra cualquier monitor serie que esté usando el puerto.
Este navegador no permite grabar el ESP32. Abre la página en Chrome o Edge. El navegador ha bloqueado el acceso al puerto USB.

Después de instalar

  1. Desde el móvil, conéctate a la Wi-Fi CamperLevel-XXXXXX.
  2. Contraseña: camperlevel.
  3. Si la página no aparece sola, abre http://192.168.4.1.
  4. En Venus OS activa Ajustes → Integraciones → Acceso MQTT.
  5. Busca su IP en Ajustes → Conectividad → Wi-Fi/Ethernet.
  6. Introduce en el ESP32 la Wi-Fi, la IP de Venus OS y las medidas de la camper. No necesitas usuario ni contraseña MQTT.
  7. Pulsa Guardar y reiniciar.
