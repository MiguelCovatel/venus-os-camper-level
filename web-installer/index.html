Camper Level

Nivelador comunitario para ESP32-C3, MPU-6500/9250 y Victron Venus OS

Firmware 1.1.0 · instalación guiada

1. Suelda las conexiones

Respeta los nombres de los pines. Los dos puentes del MPU fijan el modo I2C y su dirección.

Pulsa el croquis para ampliarlo. El MPU se alimenta con 3V3; EDA, ECL, INT y FSYNC quedan sin conectar.

Antes de conectar por USB: revisa con un multímetro que no exista continuidad directa entre 3V3 y GND.

2. Instala el firmware del ESP32

  1. Usa Chrome o Edge en un ordenador.
  2. Conecta el ESP32-C3 por USB y cierra cualquier monitor serie.
  3. Pulsa el botón, elige su puerto y confirma la instalación.

El contador aumenta solo cuando finaliza una grabación. Es orientativo y no recibe la configuración ni el número de serie del ESP32.

3. Configura el ESP32 desde el móvil

  1. Conéctate a CamperLevel-XXXXXX con la contraseña camperlevel.
  2. Si el portal no aparece, abre http://192.168.4.1.
  3. Introduce la Wi-Fi de la camper, la IP de Venus OS y las medidas entre ejes y ruedas.
  4. Deja MQTT en el puerto 1883, sin usuario ni contraseña, y pulsa Guardar y reiniciar.

4. Instala el panel en Venus OS

  1. En Venus OS activa Ajustes → Integraciones → Acceso MQTT.
  2. Activa SSH en la red local, configura la contraseña de root y anota la IP de Venus OS.
  3. Desde un ordenador abre PowerShell o Terminal y entra con ssh root@IP_DE_VENUS.
  4. Pega el siguiente comando. Descarga la versión publicada, verifica su SHA-256 e instala daemon y GUI v2.
curl -fsSL https://raw.githubusercontent.com/MiguelCovatel/venus-os-camper-level/main/scripts/install-venus.sh | sh

Al terminar, espera unos segundos y abre Lista de dispositivos → Camper Level. También aparece en Ajustes → Integraciones → UI Plugins → CamperLevel.

Las actualizaciones se instalan ejecutando el mismo comando. La configuración y el Nivel 0 se conservan.

5. Ajusta el nivel cero

  1. Nivela la camper usando un nivel de referencia.
  2. Abre Camper Level en Venus OS y comprueba las tres medidas.
  3. Pulsa Establecer nivel 0. El ESP32 guardará la referencia permanentemente.
