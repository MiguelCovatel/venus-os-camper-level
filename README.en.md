# Camper Level for Venus OS

Community levelling monitor for campers and motorhomes using an **ESP32-C3 SuperMini** and an
**MPU-6500 or MPU-9250**. It calculates pitch, roll and the lift required at each wheel, then
shows the result in Venus OS GUI v2. This level-only edition intentionally excludes gas sensors.

See the [Spanish quick start](docs/INICIO-RAPIDO.es.md). The project is released under the
[MIT License](LICENSE) at `MiguelCovatel/venus-os-camper-level`.
