# Contribuir

1. Explica el caso de uso y el hardware utilizado.
2. No incluyas credenciales, IP privadas ni datos personales.
3. Mantén separados firmware, daemon D-Bus y GUI.
4. Añade tests para geometría, estabilidad, MQTT y timeouts.
5. Ejecuta las validaciones de `docs/PUBLICAR.md`.

Los cambios de pinout, MQTT o rutas D-Bus se consideran incompatibles y deben incluir migración.
